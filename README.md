# 📔 Minha Agenda Escolar // MF_CORE

Este é o meu sistema pessoal de organização de tarefas da escola. Desenvolvi este projeto para facilitar o controle de matérias, conteúdos e prazos de entrega, tudo com um visual inspirado em interfaces cyberpunk.

## 🚀 Funcionalidades
- **Gestão de Tarefas:** Cadastro de disciplinas, capítulos e datas de início/fim.
- **Filtro por Origem:** Organização entre conteúdos do SAS, caderno ou vídeos.
- **Interface Mobile:** Otimizado para eu usar direto do celular na sala de aula.
- **Banco de Dados Real:** Sincronização instantânea com Supabase.

## 🛠️ Tecnologias
- HTML5 / CSS3 (Design com Glassmorphism)
- JavaScript (Lógica e Integração)
- Supabase (Autenticação e Banco de Dados)

## 🔒 Segurança
O projeto utiliza **Row Level Security (RLS)** para garantir que apenas eu, através do meu login, possa gerenciar minhas informações, mantendo os dados protegidos mesmo com o código público.
